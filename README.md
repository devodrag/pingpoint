# PingPoint (Minecraft 1.21.4 Fabric)

**PingPoint** — контекстная 3D-система тактических меток (пингов) для Minecraft 1.21.4 (Fabric Loader, Fabric API, Java 21), вдохновленная механиками из **Apex Legends**, **Portal 2** и **CS2**.

---

## 🎯 Основные возможности

1. **Контекстный 3D-рейкаст до 128 блоков:**
   - **Одиночный клик по блоку:** маркер `"Сюда / Внимание"` (голубой/белый цвет `0x00D4FF`).
   - **Одиночный клик по мобу/сущности:** маркер `"Враг / Опасность"` (красный цвет `0xFFFF3333`), метка жестко привязывается к UUID сущности и интерполированно следует за ней в реальном времени.
   - **Быстрый дабл-клик (< 300 мс):** принудительный сигнал `"Опасность"` в любую точку.
   - **Зажатие клавиши (hold >= 200 мс):** открывает отзывчивое круговое меню (**Radial Menu**):
     - ⬆️ **Точка / Сюда** (Голубой `◆`)
     - ↗️ **Осторожно** (Оранжевый `⚡`)
     - ↘️ **Враг / Опасность** (Красный `⚠`)
     - ↙️ **Лут / Ценность** (Золотой `★`)
     - ↖️ **Копать / Ломать** (Зеленый `⛏`)

2. **Сочный визуал и кинематика:**
   - Рендерится через `WorldRenderEvents.AFTER_ENTITIES` как 3D-билборд, обращенный к камере.
   - **Pop-in анимация:** упругий вход (0.0 -> 1.25 -> 1.0) за первые 4 тика.
   - **Hover float:** мягкое вертикальное покачивание в воздухе.
   - **Радарное кольцо:** анимированное пульсирующее кольцо и перекрестие на полу под меткой.
   - **Дистанция:** отображение расстояния в метрах (например, `48m`), с динамической компенсацией масштаба для сохранения читаемости на расстоянии.
   - **Off-screen индикаторы:** стрелочки-указатели на границе экрана (2D HUD) с указанием дистанции и типа метки, когда пинг находится вне поля зрения или за спиной.
   - **Плавное угасание:** метка активна 6 секунд (120 тиков), последние 20 тиков плавно затухает и уменьшается.

3. **Сетевая изоляция и безопасность:**
   - Полная интеграция с системой `CustomPayload` Minecraft 1.21.4 (`PayloadTypeRegistry.playC2S()` и `playS2C()`).
   - **Строгая серверная фильтрация:** сервер перед отправкой пакета проверяет `ServerPlayNetworking.canSend(targetPlayer, PingS2CPayload.ID)`. Ванильные клиенты не получают никаких кастомных пакетов и не затрагиваются модом вообще.
   - **Пространственный звук:** воспроизводится локально только клиентам с установленным модом.
   - **Защита от спама:** кулдаун 0.5с (на клиенте и сервере), ограничение до 2 активных меток на игрока (3-я автоматически удаляет самую старую).

## 🛠️ Сборка и запуск

Требуется: **JDK 21** и **Gradle**.

```bash
# Сборка мода
./gradlew build

# Запуск клиента в среде разработки
./gradlew runClient

# Запуск выделенного сервера
./gradlew runServer
```

Готовый JAR-файл будет находиться в `build/libs/pingpoint-1.0.0.jar`.

## 🎮 Управление

- По умолчанию: клавиша **`V`** (настраивается в *Options -> Controls -> Key Binds -> PingPoint*).
